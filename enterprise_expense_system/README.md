# 🚀 企业级智能差旅报销与费用合规审计系统 (Enterprise Expense & Audit System)

> 对标硅谷估值百亿美元财务科技巨头 **Ramp** 与 **Brex** 的自主财务合规中台。  
> 采用 **Clean Architecture** 分层架构，结合 **LangGraph 状态机编排 + 动态人机协同 (HITL) + Saga 资金事务补偿 + 模块化政策引擎**。
